# Installation

1. `wp plugin install rowan-edge-cache-1.0.1.zip --activate`, or upload the release ZIP through the Plugins screen.
2. Open **Rowan Edge Cache** in the sidebar and check the Diagnostics tab reads the cache directory as writable.
3. Purge once, then load three pages to start filling the cache.

Upgrading: replace the plugin directory or install the new ZIP over the old one; settings
and cache tables are untouched by an upgrade.
